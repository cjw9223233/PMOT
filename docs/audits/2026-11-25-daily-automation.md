為避開已知本機無頭 Edge 的憑證信任鏈限制，使用剛從正式 Cloudflare HTTPS 下載並通過雜湊比對的檔案，在本機 HTTP 執行真實瀏覽器 DOM 測試。只在測試頁控制可見清單與呼叫既有輪詢 callback，不更動正式報告、程式或時鐘：

1. 首頁內嵌 11/25、清單暫顯示到 11/24：選單、標題與實際內文一致載入 11/24，沒有只換日期。
2. 清單開放 11/25、呼叫程式已登記的 60 秒輪詢 callback：自動切換為 11/25，內文與正式片段相符。
3. 手動選 11/23，觸發前景／輪詢：維持 11/23 與歷史網址，不被自動切走。
4. 按「回到最新」：回到 11/25，實際內文相符，清除歷史網址參數；390px 手機版無橫向溢出。

這確認正式前端檔案的切換行為；不是宣稱正式網址已完成無頭瀏覽器互動驗收，也不是等待下一交易日自然跨日的紀錄。
